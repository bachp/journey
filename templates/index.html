The thirty-second version

Trunk-based development won for humans, but its trunk only holds code. Everything else a product is — the intent, the decisions, the behavior we promised — lived in developers' heads. Agents don't have heads: whatever they must know has to be materialized.

So we lift trunk-based development by one move. The trunk becomes the product definition, the whole product under version control under version control. The branch becomes a journey that proposes deltas to any of it, plus the decisions and evidence behind them, passing consensus gates where roles sign off. On return, the deltas merge into the definition and the journey freezes into an immutable record — the product's memory of why it is the way it is. Code becomes the disposable projection; consensus binds to intent and observable behavior.

tl;dr — the ten-second version

It's trunk-based development with one lift: the trunk holds the whole product, not just code — and the branch is a deliberation journey, carrying decisions and evidence and deltas over that whole product, which returns to the trunk as permanent understanding.
